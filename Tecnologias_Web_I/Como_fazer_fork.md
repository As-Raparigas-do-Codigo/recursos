# Como fazer fork de um projeto

O processo de fork (ou bifurcação em português) cria uma cópia do projeto que fica associada ao vosso utilizador num repositório à parte. 

Desta forma, conseguem fazer alterações e guardá-las no Github, tal como aprenderam na aula de Git.

Se já começaram a fazer alterações, podem fazer fork na mesma mas depois substituam os ficheiros deste novo projeto "forked" pelos que já têm as vossas alterações. 
Muito importante: não substituam a pasta .git!

Para fazer fork, façam login no Github, acedam ao repositório que querem bifurcar e cliquem "Fork" no canto superior direito:

![1623574183256](https://user-images.githubusercontent.com/39055313/135725158-4b3ffbdf-8bd7-43e3-ae28-3c1fe7bed9a3.jpeg)

Depois seleccionem o nome da vossa conta:

![1623574212183](https://user-images.githubusercontent.com/39055313/135725165-befd7553-5202-4df0-a2a1-7249b8f6b906.jpeg)

Quando o processo terminar, cliquem no botão de "Open with Github Desktop" e o resto já sabem:

![1623574329916](https://user-images.githubusercontent.com/39055313/135725168-49b69549-06db-4802-a4f9-efb64f4afb66.jpeg)

Este projeto é vosso e podem modificá-lo como quiserem.

Se quiserem depois contribuir as vosses alterações para o projeto original precisam de fazer um Pull Request.
