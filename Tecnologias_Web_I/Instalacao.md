# Instalação de Software 
Guia de instalação do software necessário para o curso de "Tecnologias Web"

## Google Chrome

1. Acede ao [site oficial](https://www.google.com/chrome/)
2. Clica em "Transferir o Google Chrome";
3. Clica no ficheiro executável que acabou de fazer o download;
4. Tens agora o Chrome instalado no computador.

## Sublime Text

1. Acede ao [site oficial](https://www.sublimetext.com/)
2. Clica em "Download For Windows" ou na opção que for mais indicada para o teu Sistema Operativo;
3. Clica no ficheiro executável que acabou de fazer o download;
4. Escolhe o destino onde tencionas instalar o editor de código (o predefinido serve perfeitamente);
5. Clica "Next";
6. Seleciona "Install";
7. Clica em "Finish" e verás que já tens o "Sublime Text" instalado no teu computador.
