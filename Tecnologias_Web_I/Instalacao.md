# Guia de Instalação do Software necessário para o Curso Tecnologias Web

## Google Chrome

1. Para o curso de Tecnologias Web vai ser-lhe útil ter instalado o browser Google Chrome. Se já o tem instalado salte para instalar o software a seguir. Para instalar o Google Chrome pode fazer o download do browser no site oficial https://www.google.com/chrome/
2. Clique em Transferir o Google Chrome;
3. Clique no ficheiro executável que acabou de fazer o download;
4.Tem agora o Chrome instalado no seu computador.

## Sublime Text

1. Para o curso de Tecnologias Web vai precisar de um editor de código. Pode fazer o download do editor de código, Sublime Text, do site oficial https://www.sublimetext.com/
2. Clique em Download For Windows;
3. Clique no ficheiro executável que acabou de fazer o download;
4. Escolha o destino onde tenciona instalar o editor de código. O predefinido servirá perfeitamente. De seguida clique Next;
5. Selecione Install;
6. Clique em Finish e verá que já tem o Sublime Text instalado no seu computador.
